== Description ==
Westio is a sleek and modern WordPress theme designed for cleaning service businesses, housekeepers, janitorial services, and maintenance companies. Built with Elementor, it offers full customization, responsive design, and SEO optimization to create professional websites that convert visitors into clients.

== Features ==
* Elementor Page Builder – Drag & Drop website builder
* Fully Responsive – Looks great on all devices
* One-Click Demo Import – Set up your site in minutes
* SEO Optimized – Improve your search rankings
* Fast Performance – Optimized for speed
* Multiple Homepage Layouts – Flexible design options
* WPML & Translation Ready – Create multilingual sites
* Advanced Theme Options Panel – Easy customization
* Cross-Browser Compatibility – Works on all major browsers
* WooCommerce Ready – Build your online cleaning store

== Installation ==
1. Upload the theme files to the `/wp-content/themes/westio/` directory.
2. Activate the theme via 'Appearance > Themes' in WordPress.
3. Install and activate recommended plugins for full functionality.
4. Import demo content via Theme Options.
